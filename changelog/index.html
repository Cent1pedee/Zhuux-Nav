更新日志

只记录用户能感知的变化：新收录、新功能、修复与优化。按时间倒序，最新在上。

  1. 2026-11-14

    移动端：更紧的卡片节奏与更少的紫色

    • 重构「我的收藏 / 最近浏览」的区块标题降到 17px 并去掉装饰图标，页面标题重新成为唯一的一级标题
    • 修复卡片描述不再强占两行高度：单行描述的卡片不再在描述与标签之间留出 20px 空白，卡片高度从固定 166px 变成 144 / 163px 两种
    • 修复详情页四个操作按钮在手机上排成 2×2 等宽网格，不再是「三个挤一行、反馈单独掉一行」
    • 修复移动端主按钮去掉一直在转的扫光，搜索框与结果行去掉紫色光环，顶部滚动进度条改为一条实色
    • 重构收藏页说明压成一行短句，页脚「关于」在手机上改成两列，少滚约 200px
  2. 2026-11-13

    白色底、右侧抽屉、首屏骨架与 Base UI Toast

    • 新增首屏先显示 shadcn/ui Skeleton 卡片占位（图标、标题、两行描述、标签），加载完成后与真实卡片交叉淡化；禁用 JS 时骨架自动隐藏、卡片直接可读
    • 新增主题切换通知改成逐条堆叠，带模式图标与「下次切到哪」提示，并加自动消失进度条与更柔和的进出场
    • 修复修复点击收藏后控制台出现「ResizeObserver loop completed with undelivered notifications」：通知内容不再撑满根节点，避免与 Base UI 的高度自测形成回环
    • 重构Toast 迁移到 shadcn/ui 的 Base UI 版本：右下角牌堆叠放、悬停展开、最多 4 条，文案与触发逻辑不变
    • 新增浅色主题的页面底色改为纯白，48px 网格保留并把线色提到 4%，让网格承担层次而不是靠米色底
    • 新增设置从居中模态框改为右侧滑出的 Drawer（shadcn/ui + vaul），Esc、焦点循环、滚动锁与焦点归位全部保留
    • 修复我的收藏「新建分组」补齐与分组标签同高的下边框与内距，按钮不再比同级高出一截
  3. 2026-11-13

    安静的索引：一次去 AI 味的视觉重做

    • 重构全站配色回到纸面 / 石墨底色，只保留一个紫色强调色：去掉紫蓝渐变、光斑与玻璃拟态，背景保留 48px 网格底纹
    • 重构侧栏分类与排序控件回到有动效的版本：选中块用 spring 在项目间滑动，卡片悬停轻微抬起；搜索筛选与收藏分组改用 2px 下划线
    • 重构卡片标签改成用圆点串联的索引行；分类归属只在详情页与面包屑出现，一张卡片只留一层 1px 描边
    • 重构站点详情、更新日志、隐私政策收敛为居中的 768px 阅读列，分节改用细线，不再一屏堆满卡片
    • 性能「推荐新站点」的扫光改为悬停触发，订阅按钮的圆点铺满改为 10% 主色填充，常驻动画不再抢注意力
    • 移除删除空态的流星与绕边扫光，Magic UI 组件从 14 个减到 11 个，首屏约 282KB
    • 新增推荐位卡片改用主色描边 + 顶部柔光 + 域名行「推荐」标签，替换原先几乎看不见的左侧竖条
    • 新增更新日志的类型标签改为单色文字标签，五种彩色小胶囊合并为一列可扫读的标尺
    • 新增分享图与 PWA / iOS 图标换成同一套索引卡标记：石墨卡面、纸色横线、紫色索引标签，右侧附分类索引表
    • 重构排印收口：标题收紧字距与行高、正文行高 1.6、数字改等宽对齐；欢迎弹窗与空态文案各减一句
  4. 2026-11-12

    稳定性与视觉收口

    • 新增通知改为 shadcn base toast：标题 + 描述 + 右上角关闭键，去掉图标圆底与左侧色条，固定 64px 高
    • 新增推荐位改为 30% 主色描边 + 常驻顶部柔光 + 图标光晕，不再叠绕边流光
    • 移除移除首页标题栏的重复搜索框，全站只保留顶栏一个搜索入口
    • 修复弹窗打开时不再有可见位移：面板不做入场动画，只保留遮罩淡入
    • 修复隐藏的 radio / file 控件不再撑出横向滚动条，反馈与设置弹窗内部宽度稳定
    • 修复订阅与反馈弹窗的错误行、成功态与面板高度固定，文字不再跳动
    • 修复关闭键去掉悬停旋转与按压缩放，面板出现时不会因指针停留而额外移动
    • 性能推荐新站点的扫光改用 transform 合成层动画，不再重绘整块按钮
  5. 2026-11-11

    shadcn/ui 组件体系

    • 新增全站控件迁移到 shadcn/ui + Radix：弹窗、通知、确认框、下拉、选择器、按钮、输入框、面包屑、排序与筛选
    • 新增搜索入口改为 36px 高的搜索字段，面板加宽到 672px，输入区、筛选胶囊与结果栅格重排
    • 新增排序与搜索筛选支持方向键，选中态与 aria-pressed 同步
    • 新增主题切换改用 Magic UI AnimatedThemeToggler，连点不丢点击、提示不堆叠
    • 修复嵌套弹层第二次 Esc 不再丢失，滚动锁不残留
    • 修复Toast 不再抢走 Esc；只在没有菜单 / 选择器时关闭最上层弹窗
    • 修复弹窗开合时背景不再横向位移，菜单不再被裁剪
    • 修复浅色主题下的对比度与跨页样式统一
    • 性能主题过渡改为快照交叉淡化，约 42fps → 59fps；滚动 p95 22.8ms → 18.8ms
    • 重构Modal / Toast / Confirm 保留原 API 与业务语义，内部换成 Radix；首屏约 235KB → 285KB，预算改为只测量
